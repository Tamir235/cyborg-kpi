## Ablauf

### Schritt 1 – Fragestellung klären
- Was genau soll erforscht werden?
- Themengebiet: Skill-Progression / Kraft / Ausdauer / Ernährung / Recovery / Verletzung?
- Geht es um: Threshold, Technik, Verletzungsrisiko, Timing, Dosierung oder Timeline?

### Schritt 2 – Recherche durchführen
- Quellenliste für das jeweilige Themengebiet (siehe oben) nutzen
- Primärquellen direkt fetchen (URLs), nicht aus dem Gedächtnis zitieren
- Auf die Fragestellung relevante Abschnitte identifizieren und direkt zitieren

### Schritt 3 – Cross-Check
- Mindestens 2 unabhängige Primärquellen für jede Behauptung
- Bei Widersprüchen: beide Werte nennen + Kontext erklären
- Keine Sekundärquellen (YouTube-Zusammenfassungen, Reddit, Blog-Posts ohne Quellenangabe) als einzige Basis

### Schritt 4 – Verifikations-Status setzen

| Symbol | Bedeutung |
|---|---|
| ✅ Verifiziert | ≥2 unabhängige Primärquellen |
| ⚠️ Teilweise | 1 Quelle, oder indirekt abgeleitet |
| ❌ Nicht verifiziert | Kein Primärquelle gefunden |

### Schritt 5 – Ausgabe-Format

```
## [Skill-Name / Fragestellung]

**Befund:** [Klare Antwort auf die Frage]

**Details:**
- [Wichtige Information 1] ✅/⚠️/❌
- [Wichtige Information 2]

**Widersprüche / Einschränkungen:**
- [Falls vorhanden]

**Quellen:**
- [Quelle 1](URL)
- [Quelle 2](URL)
```

### Schritt 6 – In Wiki eintragen
Nach Bestätigung durch User:
- **Calisthenics-Themen** → `calisthenics-wiki.md`
- **Ernährungs-Themen** → `nutrition-wiki.md` (anlegen falls nicht vorhanden)
- **Recovery/Gesundheits-Themen** → `recovery-wiki.md` (anlegen falls nicht vorhanden)
- Verifikations-Status korrekt setzen
- Quellen hinzufügen
- Cross-Unlock-Tabelle aktualisieren falls relevant

## Qualitätsregeln

```
✓  Nur was in Primärquellen steht
✓  Bei Widersprüchen beide Seiten zeigen
✓  Timelines immer als Range (nicht als Einzelwert)
✓  Dosierungen immer mit Quelle und Körpergewichtsbezug
✓  "Intermediär" definieren: hier = solide Basis in der Bewegungskategorie
✗  Keine Schätzungen ohne Quellenangabe
✗  Keine Reddit/YouTube-Threads als alleinige Basis
✗  Keine Vermischung von Mastery-Zielen und Mindest-Schwellen
✗  Keine allgemeinen Aussagen ohne Kontext ("es kommt drauf an" ist keine Antwort)
```

## Wichtige Unterscheidung

```
Mindest-Schwelle (minVal):   Floor um zum nächsten Skill zu beginnen
Persönliches Ziel (target):  Was der User individuell anstrebt
Meisterschaft (mastery):     Was Coaches als "fertig" definieren

Beispiel HBH:
  minVal:  30s  → Dragon Flag Entry (Calisthenics Nerd)
  target:  45s  → Vom User selbst gesetzt
  mastery: 60s  → BWTA interne Benchmark

Beispiel Protein:
  minVal:  1.6g/kg  → Minimale Muskelerhalt-Schwelle (PubMed Meta-Analyse)
  target:  2.0g/kg  → Praktische Empfehlung für Kraft+Ausdauer
  mastery: 2.2g/kg  → Upper-range für Hypertrophie-Optimierung
```
