# /status

Zeige aktuellen Projekt-Status ohne alle Dateien neu zu lesen.

## Ausgabe

```
╔══════════════════════════════════════╗
║   📊 Cyborg KPI · Status             ║
╚══════════════════════════════════════╝

Backlog Übersicht:
  🔴 P1 Safety:      [X/3 erledigt]
  🟡 P2 Core UX:     [X/5 erledigt]
  🟠 P3 Navigation:  [X/6 erledigt]
  🟠 P4 Module:      [X/? erledigt]
  🎮 P5 Features:    [X/? erledigt]
  🟢 P6 Polish:      [X/5 erledigt]

Nächster Task: [ID] – [Beschreibung]

Aktuelle Session: [was bisher gemacht wurde]
══════════════════════════════════════
```

## Verwendung
Schneller Überblick mitten in einer Session ohne `/start-session` neu auszuführen.
